Scarica PitStudio

Un solo file per Windows: comprende l'interprete, PitStudio e, se vuoi, le librerie scientifiche. Gratuito, senza Python e senza diritti di amministratore.

Versione 2.34 per Windows

Windows 10 o 11, 64 bit. Circa 110 MB.

Come si installa

Quattro passaggi, nessun amministratore.

  1. Scarica il file

    Salva Installa_pytonIta.exe dove vuoi.

  2. Avvialo con un doppio clic

    Si scompatta in una cartella temporanea, installa e si cancella da solo.

  3. Scegli i componenti

    Interprete e PitStudio sono sempre inclusi. Le librerie scientifiche (numpy, pandas, scipy, matplotlib) sono facoltative. Si installa in %LOCALAPPDATA%\Programs\pytonIta.

  4. Apri PitStudio dal menu Start

    Scegli «Una lezione» o «Un nuovo progetto» e premi F5.

Windows mostra «Windows ha protetto il PC»? È normale: il file non è ancora firmato digitalmente (la firma richiede un certificato a pagamento). Scegli Ulteriori informazioni → Esegui comunque. Se preferisci verificare, confronta l'impronta SHA-256 qui sopra con quella del file scaricato, per esempio con Get-FileHash Installa_pytonIta.exe in PowerShell.

Linux

Non c'è un installatore precompilato: lo script installa.sh compila l'interprete e installa PitStudio. Le istruzioni sono nella cartella installatore/linux del repository.

macOS

Non ancora supportato.

Aggiornamenti

PitStudio controlla da solo le nuove versioni (Aiuto → Controlla aggiornamenti) e scarica l'installatore da GitHub. Non serve disinstallare: l'installatore aggiorna e rileva i programmi aperti.

Disinstallare

Dalle impostazioni di Windows (App) o dal menu Start. Non tocca il tuo Python né le altre tue installazioni.

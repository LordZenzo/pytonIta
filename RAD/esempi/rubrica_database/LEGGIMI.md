# Rubrica con database

Apri `mascheracontatti.pit` e scegli *Esegui → Esegui il file corrente*.

- La finestra (`mascheracontatti.form.json`) si modifica nel progettista.
- I dati sono in `rubrica.db`: aprilo con un doppio clic nell'albero del progetto per vederli e cambiarli (scheda *Database*).
- `fonte_dati.pit` collega la tabella alla finestra: è usabile anche in altre finestre.

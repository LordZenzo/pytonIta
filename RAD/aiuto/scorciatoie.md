# Scorciatoie da tastiera

Le scorciatoie di *File*, *Esegui* e *Visualizza* si possono cambiare nelle [impostazioni](#impostazioni).

## Generali

| Scorciatoia | Azione |
|---|---|
| **F1** | guida (con il cursore su una parola del codice: la sua scheda) |
| **Ctrl+O** | apri progetto |
| **Ctrl+N** | nuovo file |
| **Ctrl+S** | salva |
| **Ctrl+Maiusc+S** | salva tutto |
| **Ctrl+W** | chiudi la scheda |
| **Ctrl+J** | mostra/nascondi l'assistente |
| **F5** | esegui il programma |
| **Maiusc+F5** | ferma |
| **F6** | avvia il debugger |
| **F9** | punto di arresto sulla riga del cursore (o clic sul margine) |
| **F10** / **F11** / **Maiusc+F11** | durante il debug: passo / entra / esci dalla funzione |
| **F5** (in debug) | continua fino al prossimo punto di arresto |
| **Ctrl +** / **Ctrl −** | ingrandisci / riduci il testo |

## Editor di codice

| Scorciatoia | Azione |
|---|---|
| **Ctrl+Spazio** | mostra i suggerimenti |
| **Tab** / **Invio** | accetta il suggerimento; **Tab** dopo un frammento (`se`, `per`…) lo espande |
| **Esc** | chiude i suggerimenti |
| **Maiusc+Tab** | riduce il rientro (anche su più righe) |
| **Ctrl+/** | commenta/decommenta |
| **Ctrl+D** | duplica la riga |
| **Alt+↑ / Alt+↓** | sposta la riga |
| **Ctrl+F** | trova e sostituisci |
| **Ctrl+G** | vai a riga |
| **Ctrl+Z / Ctrl+Y** | annulla / ripeti |
| **Ctrl+A** | seleziona tutto |

## Progettista di finestre

| Scorciatoia | Azione |
|---|---|
| **Frecce** / **Maiusc+frecce** | sposta il componente di 1 / 10 punti |
| **Maiusc+clic** | aggiunge alla selezione |
| **Ctrl+C / Ctrl+V / Ctrl+D** | copia, incolla, duplica |
| **Canc** | elimina |
| **Ctrl+Z / Ctrl+Y** | annulla / ripeti |
| **Ctrl+A** | seleziona tutto |

## Programmi a mattonelle

| Azione | Come |
|---|---|
| Staccare una mattonella e le seguenti | trascinala |
| Staccare **solo** quella mattonella | **Alt** + trascina |
| Eliminare | trascina sulla tavolozza, oppure **Canc** |
| Duplicare | **Ctrl+D** o clic destro |
| Annulla / ripeti | **Ctrl+Z / Ctrl+Y** |
| Zoom | **Ctrl + rotella** |
| Spostare la vista | trascina lo sfondo; **rotella** in verticale, **Maiusc+rotella** in orizzontale |

## Albero del progetto

| Scorciatoia | Azione |
|---|---|
| **Invio** / doppio clic | apri |
| **F2** | rinomina |
| **Canc** | elimina |
| clic destro | menu del file |
